# AlToke Pro - Repositorio Comercial y de Producto

**Tu inventario al tiro, sin atados.**

Este repositorio (`AlTokePro`) contiene la documentación comercial, marketing, manuales de usuario y recursos para la Play Store de **AlToke Pro**.

> **Nota Técnica:** Para ver el código fuente de la aplicación (Next.js, FastAPI, Base de datos), dirígete al repositorio **StockMasterPWA**.

---

## 🎯 Propuesta de Valor y Características Comerciales

*   **Soporte Multimoneda Inteligente:** Configuración flexible de divisa a nivel de usuario, reflejando transacciones en CLP, USD, EUR, o cualquier moneda configurada de forma nativa.
*   **Códigos QR por Ubicación (Estanterías y Pasillos):** Generación automática de códigos QR para áreas específicas, estanterías o pasillos. El cliente puede escanear el QR con la app para auditar y ver instantáneamente todos los productos de esa área, agilizando el control y reposición de stock.
*   **Auditorías Avanzadas y Sugerencias de Reposición:** Permite auditar pasillos o estantes, comparando inventario físico con sistema, gestionando productos mal ubicados e indicando conteos precisos para reposición.
*   **Escaneo Inteligente Integrado:** Permite registrar movimientos de entrada y salida utilizando la cámara del dispositivo móvil o mediante pistolas lectoras de códigos de barra USB tradicionales.
*   **Operación Ininterrumpida (Modo Offline):** Diseñado para trabajar sin señal. Los registros realizados en bodegas sin conectividad o subterráneos se resguardan de forma segura en el dispositivo y se sincronizan automáticamente con la nube al recuperar la red.
*   **Gestión Multi-Sucursal Avanzada:** Controla el inventario de múltiples bodegas o puntos de venta desde una interfaz única y centralizada.
*   **Alertas Inteligentes de Reposición:** Sistema de notificaciones en tiempo real que avisa al celular cuando un producto de alta demanda alcanza su umbral mínimo de stock.
*   **Exportación de Datos:** Descarga reportes y hojas de análisis directo a planillas de cálculo (Excel/CSV) con un solo clic.
